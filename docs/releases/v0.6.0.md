<h2 id="cn-v0.6.0">本次更新</h2>

- **升级至 `dsh-v0.1.5-rc.2`**：支持任意类型附件上传、模型交付文件，以及 Markdown、代码、HTML、PDF 和图片预览。改进长会话、消息队列、模型配置与反馈提交；支持在模型明确声明兼容时动态更新系统提示词并保留 KV Cache。
- **统一右侧 Tabs**：采用 DSH 的标签页、分屏、浮动和全屏容器，兼容 Minke 的文件、终端、网页、历史和插件标签。新增菜单区分 DSH 与 Minke，保留 Minke 文件管理风格和独立底栏。
- **完善本地模型服务**：LM Studio 与 Ollama 的开关、错误和状态独立展示；修复 Ollama 没有已下载模型时无法正常启动的问题。
- **打磨日常操作**：优化 macOS 拖动区域、按钮、滚动和浏览历史；修复标签图标与加载动画。文件预览可切换效果、源码和 Diff，关闭按钮始终可见。
- **支持慢加载重试**：页面加载失败后可重新加载，复用已启动的 DSH 后端，并支持调整等待时间。

## 升级说明

- **Session V3**：受支持的历史会话会迁移为新的日志文件，原日志保留。旧版本无法读取 V3 的新增记录，升级前建议备份当前数据目录。
- Codex / Claude Code 子代理插件需要另行安装并启用；DSH Agent Teams 仍是需要显式配置的实验功能。
- 第三方插件需兼容 DSH 的 Agent、Inbox 和面板 API 变更。安全模式会跳过第三方插件启动，并保留安装，便于排查与恢复。

感谢 DeepSeek Harness 的贡献者，以及帮助测试和反馈 Minke 的用户。

<h2 id="en-v0.6.0">What's new</h2>

- **Upgrade to `dsh-v0.1.5-rc.2`**: Upload arbitrary file types, receive files delivered by the model, and preview Markdown, code, HTML, PDFs, and images. This update improves long conversations, message queues, model configuration, and feedback submission. Dynamic system prompt updates preserve the KV cache when the configured model explicitly supports them.
- **Unified right Sidebar tabs**: Use DSH's tabs, split panes, floating panes, and fullscreen container with Minke's Files, Terminal, Browser, History, and Plugins tabs. The creation menu groups DSH and Minke entries, while Minke keeps its file manager style and independent bottom panel.
- **Independent local model services**: LM Studio and Ollama have separate switches, errors, and running states. Fix Ollama startup when no models have been downloaded.
- **Everyday UI improvements**: Refine macOS drag regions, buttons, scrolling, and Browser History; fix tab icons and loading animations. File previews switch between rendered content, Source, and Diff, with Close always visible.
- **Retry slow page loads**: Reload after a page load failure while reusing the running DSH backend, with configurable timeouts.

## Upgrade notes

- **Session V3**: Supported historical sessions migrate to new log files while the originals are preserved. Older versions cannot read new V3 records; back up your current data directory before upgrading.
- Codex / Claude Code subagent plugins require separate installation and activation. DSH Agent Teams remains experimental and requires explicit configuration.
- Third-party plugins must support DSH's Agent, Inbox, and panel API changes. Safe mode skips third-party plugins at startup while keeping them installed, making troubleshooting and recovery reversible.

Thanks to the DeepSeek Harness contributors and everyone testing Minke and sharing feedback.
