<h2 id="cn-v0.8.0">本次更新</h2>

- **升级至 `dsh-v0.1.7-rc.2`**：支持在侧栏预览 Office 文档、审阅回合文件变更，以及查看计划和子代理会话。
- **统一插件与终端体验**：使用 DSH 原生插件管理和终端，保留插件发现、安全模式及独立底栏；侧栏与底栏共享终端外观设置，刷新后可恢复连接。
- **修复本地模型启动**：LM Studio、Ollama 的发现与启动接入原生模型配置，保留已保存的提供方和实时设置更新。
- **改善桌面交互**：新增标签使用分组下拉菜单，保留分屏、文件和终端入口；修复按钮重叠、侧栏图标隐藏及 macOS 顶部拖拽不稳定的问题。
- **简化反馈与导出**：Feedback 直接打开 Minke Issues，关闭上游会话反馈上传；导出会话时不再弹出准备或开始下载提示，失败信息仍保留。
- **优化安装包**：改进 macOS、Linux 安装包压缩，并加强各平台的体积校验和侧栏界面回归检查。

**升级提示**：升级前建议备份 Data Home。DSH 会迁移会话格式与 Profile 配置，升级后的数据不适合交给旧版运行。旧插件禁用状态会自动迁移，不兼容的第三方插件需要更新。Minke 备用网页搜索改为显式调用，原生网页工具的错误保持原样。详见[升级说明](https://github.com/lencx/Minke/blob/v0.8.0/docs/dsh-upgrade.md)。

<h2 id="en-v0.8.0">What's new</h2>

- **Upgrade to `dsh-v0.1.7-rc.2`**: Preview Office documents, review each turn's file changes, and open plans and subagent conversations in the sidebar.
- **Unify plugins and terminals**: Use DSH's native plugin manager and terminal while retaining plugin discovery, safe mode, and the independent bottom panel. Both terminal placements share appearance settings and restore connections after refresh.
- **Fix local model startup**: Integrate LM Studio and Ollama discovery and startup with native model settings, preserving saved providers and live configuration updates.
- **Refine desktop interactions**: Add grouped tab menus while retaining split views, files, and terminals. Fix overlapping controls, hidden sidebar icons, and inconsistent macOS titlebar dragging.
- **Simplify feedback and exports**: Open Minke Issues directly from Feedback and disable the upstream session feedback uploader. Remove preparation and download-started dialogs from session exports while retaining errors.
- **Improve packaging**: Improve macOS and Linux installer compression, with size checks and sidebar UI regression coverage across package targets.

**Upgrade notes**: Back up Data Home before upgrading. DSH migrates session formats and Profile configuration; upgraded data is unsuitable for older versions. Legacy plugin disablement is migrated automatically, and incompatible third-party plugins need updating. Minke's additional web search is now explicitly invoked, leaving native web-tool errors unchanged. See the [upgrade guide](https://github.com/lencx/Minke/blob/v0.8.0/docs/dsh-upgrade.md).
